# 电商带货专用画布实施计划

**目标：** 复用现有无限画布与视频接口，加入分类化的电商视频批量生成入口。

**架构：** 模板配置负责分类文案与预置节点，画布项目保存可选的电商工作流元数据；电商入口创建模板项目，项目页根据元数据展示批量生成控制并调用现有视频接口。

**技术栈：** Vite、React、TypeScript、React Router、Zustand、Ant Design。

---

1. 新增电商模板类型与模板工厂，生成商品图、创意说明、视频配置节点和连线。
2. 扩展画布项目存储，持久化电商分类、商品节点和默认批量数量。
3. 新增电商分类页、路由和顶部/移动端导航入口。
4. 在专用画布加入商品图上传、1-100 数量选择和一键生成按钮。
5. 使用现有视频接口实现最多并发 3 条的批量任务，并将任务状态与结果写回视频节点。
6. 启动开发页，人工检查入口、模板画布和控制区是否可见；按用户要求不新增或运行自动化测试。
