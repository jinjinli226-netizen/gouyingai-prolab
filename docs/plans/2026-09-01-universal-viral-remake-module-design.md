# 通用爆款复刻独立模块设计

## 需求摘要

在不修改现有爆款复刻内部结构的前提下，新增一套可快速开发、易扩展的“通用复刻 Beta”。它只有一种用户模式：上传参考视频，可选上传替换对象，系统忠实重建原片结构，校验后替换对象并生成完整成片。

模块必须同时支持：

- 单条生成与 1–1000 条批量扩产，共享同一份已验证母版。
- 长视频复刻。目标模型单次最多生成 15 秒时，按语义边界拆成多个片段任务，完成后自动合成一条视频。
- 提示词优先。参考视频用于理解和校验，不要求目标视频模型支持视频参考。
- 对象替换不能改写未授权的动作、时间轴、镜头或声音。
- 旧爆款复刻入口、类型、节点、队列和历史画布继续工作。

## 方案比较

### 方案 A：独立模块化单体（采用）

在当前 Web 和 Gateway 中分别新增 `universal-viral-remake` 目录，通过公开入口和少量适配器连接画布、模型与任务系统。核心领域与编译逻辑是纯 TypeScript，不依赖 React、存储或具体供应商。

优点是开发快、部署方式不变、模块边界清晰、可独立测试；缺点是仍与现有应用一起发布。

### 方案 B：复制旧工作流后修改

最初看起来最快，但旧类型、固定营销字段和自由策划器会被复制进去，两条链路很快分叉，后续修复需要重复进行，因此不采用。

### 方案 C：独立微服务

隔离和独立扩缩容最好，但需要单独部署、鉴权、监控和数据一致性设计，当前阶段增加的运维成本高于收益，因此不采用。

## 高层架构

```text
通用复刻 Beta 画布入口
        |
        v
Canvas Adapter（只负责 UI 与端口调用）
        |
        v
Universal Remake Core（纯 TypeScript）
  ├─ Source Reconstruction
  ├─ Verification
  ├─ Entity Binding
  ├─ Fidelity Diff Gate
  ├─ Semantic Segmenter
  ├─ Model Prompt Compiler
  └─ Batch/Candidate Manifest Compiler
        |
        v
Gateway Universal Remake Runtime
  ├─ 有界候选队列
  ├─ 片段视频子任务
  ├─ 连续性传递
  ├─ FFmpeg 合成任务
  └─ 完整候选结果
```

旧爆款复刻不会导入新模块，新模块也不会读取旧工作流的内部状态。两者只复用稳定的底层能力：视频生成调用、画布私有素材、费用配置和结果展示组件。

## Web 模块边界

新增目录：

```text
web/src/lib/universal-viral-remake/
  types.ts
  reconstruction.ts
  verification.ts
  binding.ts
  fidelity.ts
  segmentation.ts
  prompt-compiler.ts
  batch-compiler.ts
  engine.ts
  index.ts
```

`engine.ts` 是唯一公开门面。外部只能通过 `createUniversalViralRemakeEngine(ports)` 使用模块，不直接拼装内部步骤。

端口保持最小：

```ts
type UniversalRemakePorts = {
  understandVideo(request: VideoUnderstandingRequest): Promise<string>;
  submitRun(request: UniversalRemakeRunRequest): Promise<{ runId: string }>;
};
```

视频模型差异通过 `PromptCompiler` 注册，不在核心流程写模型名称判断。第一版只提供一个通用编译器和现有默认模型适配器，后续按需增加。

## 唯一通用母版

核心产物为 `UniversalRemakeTemplate`：

- 已验证的原片标准导演提示词。
- 自适应时间单元及证据。
- 原片对象与稳定占位符。
- 用户确认的对象绑定。
- 可选局部补丁。
- 语义差异报告。
- 生成片段计划与连续性契约。

不存在冲突、反转、揭晓、CTA 等必填分类，也不存在多种复刻模式。静态姿态、朝向、机位和光线只在当前视频需要时出现在连续导演描述中。

## 长视频语义拆分

模型最大时长来自能力目录，不能把 15 秒写死在业务逻辑中；当前默认上限为 15 秒。

拆分优先级：

1. 原片真实硬切、转场或时空跳变。
2. 动作目标完成、物体状态稳定或说话语义完整的时间单元边界。
3. 模型在长连续单元中识别出的安全延续点。
4. 只有前三项都不存在时才创建强制连续边界，并明确标记风险。

算法从前向后组合相邻时间单元，尽量接近但不超过模型上限。任何单元自身超过上限时，必须使用其 `safeContinuationPointsSeconds` 继续拆分；没有安全点时返回 `needs-refinement`，不得静默硬切。

每个片段生成一个 `ContinuityContract`：

- 片段开始和结束时的人物身份、服装、位置与动作阶段。
- 商品、道具和场景状态。
- 镜头位置、方向、运动趋势、焦点和曝光状态。
- 原片声音、对白、字幕和音乐延续状态。
- 是否允许硬切、直接拼接或短过渡。

支持尾帧参考的模型，在下一片段提交前使用上一片段尾帧；不支持时，将连续性契约编译进下一片段提示词。连续片段默认顺序生成，避免下一片段在前一片段状态未知时先提交。

## 合成策略

Gateway 新模块读取当前画布拥有的片段产物，只允许私有 artifact URI，禁止下载任意外部地址。

合成前把片段规范化为同一分辨率、画幅、帧率、视频编码和音频采样率：

- 原片硬切边界：直接 concat。
- 连续动作边界：使用生成时预留的短句柄裁切；必要时使用 80–160ms 的视频/音频过渡，不能凭空增加总时长。
- 最终时长按母版精确裁切，允许误差不超过 0.1 秒。
- 第一版使用片段原生音频；接口保留 `global-track` 策略，未来可统一合成口播、音乐和音效。

FFmpeg 不可用、片段缺失、编解码失败或最终时长超差时，候选失败但不影响同批其他候选。原始片段继续保留以便重试合成，不重复付费生成。

## 批量执行

数量默认 1，范围 1–1000。1000 是容量上限，不是默认任务。

批量编译时：

- 一份已验证母版编译 N 个候选 manifest。
- 母版时间轴、未授权动作和固定对象绑定不可变。
- 只有用户声明的变量槽位可变化；槽位选择在一条候选的全部片段中保持固定。
- 一个候选在 UI 和结果库中始终是一条完整视频，即使后台包含多个片段任务和一个合成任务。
- 总费用按所有候选的片段时长和合成成本预估，提交前展示。
- 默认不试跑、不扩产、不自动付费重试。

Gateway 使用两级有界并发：候选级窗口控制同时运行的候选数；每个候选内部按连续性要求顺序生成片段。短视频只有一个片段，直接复用同一执行模型，无特殊分支。

## 状态与失败隔离

```text
draft
 -> reconstructing
 -> verifying
 -> binding_ready
 -> compiled
 -> ready_to_submit
 -> queued
 -> generating_segments
 -> composing
 -> completed | failed | paused | cancelled
```

- 更换原片使母版和全部未提交候选失效。
- 更换替换素材只重新绑定和编译，不重新理解原片。
- 修改数量只重新编译候选清单。
- 单个片段失败只影响所属候选。
- 合成失败可以只重试合成。
- 页面刷新或关闭不取消 Gateway 中的运行任务。

## 非功能要求

- 兼容性：旧爆款复刻测试必须全部继续通过。
- 扩展性：新增模型只实现编译器；新增校验规则只注册规则。
- 性能：核心编译与拆分对 1000 个候选使用有界循环，不创建无界 Promise 集合。
- 安全：合成只读取同一用户、同一画布拥有的 artifact；FFmpeg 参数使用参数数组，不拼接 shell 命令。
- 可观测性：run、candidate、segment 和 composition 都有稳定 ID、状态、错误码和耗时。
- 费用：任何视频片段任务创建前都有候选数、片段数、总秒数和预计费用。

## UI

旧“爆款复刻”入口保持原样，旁边新增“通用复刻 Beta”。新入口创建独立工作流节点，只显示：

1. 参考视频。
2. 通用复刻素材与对象绑定。
3. 已验证通用母版。
4. 批量与长视频执行计划。
5. 完整成片结果库。

长视频卡片显示原片总时长、片段数量、各片段时间范围、连续性边界、预计调用次数与费用，但镜头/动作节拍不被称为变体或独立成片。

## 验收

- 旧爆款复刻源码测试和 UI 测试全部通过。
- 新核心模块不导入 React、画布节点、存储实现或旧爆款复刻模块。
- 安静展示、口播、ASMR、一镜到底物理动作、多切镜和换装视频都能形成母版，不需要固定营销标签。
- 8 秒视频产生一个片段；31 秒视频在语义边界形成至少三个、每个不超过 15 秒的片段。
- 不存在安全延续点的超长单元返回 `needs-refinement`。
- 1000 个候选共享母版且固定绑定不漂移。
- 每个长视频候选完成后只向结果库写入一条合成视频。
- 片段合成后最终时长误差不超过 0.1 秒。
- 未授权的动作改写在任何视频任务创建前被语义差异门禁阻止。
