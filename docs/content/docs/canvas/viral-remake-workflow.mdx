# 爆款复刻工作流

爆款复刻只有一种模式：保留原片已经验证的事件结构、时间线、镜头意图与卖点表达，用自动识别或用户上传的人物、商品、场景等对象生成原创同款。候选数量始终表示完整视频数量，不是镜头数量或提示词变体。

## 五张主卡

1. **参考视频**：上传一条完整原片。
2. **复刻素材与对象识别（可选）**：系统识别原片对象和 P0/P1/P2 事件，也识别上传素材并自动绑定；不上传素材仍可继续。
3. **复刻母版**：固定完整时间线、必保事件、人物与服装连续性、商品事实、音频计划和镜头节拍。所有 P0 事件必须恰好覆盖一次。
4. **批量生产**：设置 1–1000 条完整候选。系统只改变允许变化的人物表演细节、场景表面或文案表达，不改母版事件和已绑定对象。
5. **成片结果库**：分页查看成功、运行和失败候选，支持暂停、继续、取消和重试失败项。

## 生成门禁

付费任务提交前必须同时满足：对象绑定无冲突、母版覆盖全部 P0、目标时长可执行、费用预估已显示并在超额时获得明确授权。原片时长默认保持不变；模型时长不足时优先使用单次编排的连续分段能力，否则只允许保留全部 P0 的显式压缩，无法满足则停止。

Gateway 使用稳定幂等键和有界并发窗口。即使请求 1000 条，画布也只保留一张结果库卡片；候选任务和状态由 Gateway 持久化，刷新或 Gateway 重启后可以恢复，不会因重复点击创建同一批次或重复扣费。

## 质量门禁

成片评分采用固定权重：事件覆盖 30%、时间线 20%、人物一致性 15%、商品还原 15%、声音 10%、画面 10%。报告必须给出证据、问题原因和修复建议。缺失任何 P0 事件时总分上限为 79，只能重试或人工复核，不能标记为高质量复刻。

## 当前验证边界

自动化测试覆盖领域契约、对象识别与绑定、母版覆盖、时长策略、确定性候选编译、1000 条有界批次恢复、分页、状态机、质量评分、费用授权和幂等。测试不会调用真实付费模型；真实渠道仍需验证视觉识别、音画复刻、上游价格和生成质量。
