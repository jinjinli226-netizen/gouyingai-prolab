- 已完成（多画布并行）：浏览器不设置提交上限，每个画布独立保存；Gateway 按全局、能力和渠道并发限制公平调度，并提供跨画布任务中心、取消和重试。

- 已完成（爆款复刻）：后续分镜提示词策划只依赖 `analysisNodeId`，不再读取 `analysisShotNodeIds`。
- 已完成（爆款复刻）：单张替换图节点升级为可折叠的“替换元素（可选）”大卡片；拉片自动列出具体人物、场景、商品、车辆和关键物品，每个对象可绑定多张参考图，也可以零素材直接纯 AI 复刻。
