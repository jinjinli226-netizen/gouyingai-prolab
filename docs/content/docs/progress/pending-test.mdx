# 待测试

- 通用复刻 Beta 一键成片导演稿：复刻母版不再把对象清单、能力覆盖、置信度和事件数据库直接提交给视频模型；生成前会把已验证事件图与替换对象编译为 `Duration / Aspect ratio / Style / VISUAL REFERENCES / SCENE / SHOT BREAKDOWN / NEGATIVE CONSTRAINTS` 结构的自然语言导演提示词。导演稿必须覆盖全部关键事件、明确写出替换后的可见终止状态、保持单实例与连续动作，并让每个生成片段使用从 0 秒开始且连续覆盖本段的本地时间轴；结构、时长、画幅、关键事实或终止状态不合格时会携带具体错误自动纠正一次。终止状态只在逐秒画面中使用同义描述时，系统会把明确状态自动补入最后一个时间段，不再误判中止；母版编译仍失败时保留已完成拉片，并在错误卡片直接提供“继续生成母版”。批量变量只替换对象身份与对应参考图，不改事件结构。仍需用真实多模态文本模型重新生成复刻母版，再用真实视频模型核对最终导演稿和成片效果。

- 通用复刻 Beta：`/ecommerce` 应同时显示原“爆款复刻”和新的“通用复刻 Beta”卡片；点击新入口应创建独立五卡片画布，依次完成双重语义拉片、可选多对象替换与绑定、唯一保真母版、1–1000 条完整候选的费用预检和后台提交、成片结果预览。长视频应按模型时长能力在安全语义边界分段，候选内部顺序生成并自动合成为一条最终视频；暂停、恢复、取消和仅重试合成不应重复生成已成功片段。代码层已通过 Web 180 项测试、Gateway 72 项测试和真实 FFmpeg 合成测试，未调用付费模型；仍需使用真实模型人工验证双重拉片质量、跨段连续性、批量调度与最终成片效果。

- 爆款复刻母版批量工作流：画布固定为“参考视频 → 复刻素材与对象识别（可选）→ 复刻母版 → 批量生产 → 成片结果库”五张主卡。拉片需自动识别原片对象、证据和 P0/P1/P2 必保事件；上传的人物、商品、场景等多组素材需自动识别并保守绑定，不上传仍可生成。母版默认等于原片时长，模型时长不足时只能在保留全部 P0 的前提下续写或压缩。候选数量为 1–1000 条完整成片，不是镜头变体；大批次只在 Gateway 有界窗口中创建任务，刷新/重启可恢复，画布不创建 1000 个节点。成片结果库支持分页、状态筛选、暂停、继续、取消和失败项重试。提交前显示单条/总预计费用，超过额度需明确确认，相同母版与配方的重复点击必须幂等。质量评分固定按事件覆盖 30%、时间线 20%、人物 15%、商品 15%、声音 10%、画面 10%，缺失任何 P0 时总分不得超过 79。代码测试未调用真实付费模型；仍需用真实文本、视频和质量评估渠道验证自动识别精度、原片完整复刻度、音画同步、长视频策略、价格配置与 10 次中至少 8 次达到目标相似度的验收口径。

- 爆款复刻多元素替换卡片：拉片后应在一个可拖动、可折叠的大卡片中列出具体可替换人物、场景、商品、车辆和关键物品；每个对象可以同时上传多张多角度参考图，也可以同时替换多个对象。完全不上传素材时仍可直接进入纯 AI 复刻；上传素材后，策划请求和最终视频任务应按卡片中的对象绑定关系携带全部图片，同一对象多图不得被当成多个变体，不同对象素材不得混用。低置信度、识别失败或跨类型素材现在显示“确认用于替换”，用户确认后以素材所在的原片对象槽位为准，生成上传对象指纹并锁定全片事件。确认后的素材清单必须明确写成“原片对象 → 替换对象”，用户填写的改造要求必须逐字置顶写入可编辑母版并继续传给最终视频任务，不能被 AI 策划省略或改回原对象。需人工验证批量上传、缩略图、重命名、删除、折叠、刷新恢复、人工确认绑定、改造要求持久化和多图视频模型的真实生成效果。

- 爆款复刻语义拉片：拉片先识别真实剪辑镜头，再按人物动作/姿态/位置、关键物体状态、运镜阶段、叙事功能或可确认声音事件的变化识别镜头内动作节拍；不按固定秒数、平均间隔或采样帧数量机械切分。一镜到底允许多个节拍共用同一真实镜头编号，并记录每段开始状态、结束状态和连续关系。首次结果若把多个顺序动作合并或缺少语义状态，系统会基于同一批媒体证据自动细化一次；二次仍不合格则阻止进入生成。复合节点继续展示完整代表帧，行标题压缩为动作节拍、真实镜头和时间范围，图片下只显示一行边界原因；开始状态、结束状态和承接状态保留在分析数据与生成提示词中，不在主界面重复展开。需用一镜到底和多切镜视频分别复测节拍边界、状态交接、条件细化与复合节点展示；无论分析出多少节拍，每套创意仍只能提交一次完整付费视频任务。

- 原生爆款复刻入口：任意普通画布底部工具栏新增“爆款复刻”。选中一个已上传的视频节点后点击，当前画布应保留已有节点、创建一个可选的替换元素素材库大卡片并自动开始拉片；未选中视频时应创建新的专用复刻画布。拉片完成后的主按钮统一为“一键生成复刻视频”，点击后应先生成可编辑策划节点，再只自动提交一次完整成片任务，不应要求第二次点击或按分析镜头拆成多次付费任务。需用真实文本模型与视频模型验证自动拉片、多元素绑定、零素材纯 AI 复刻、一次性自动续跑、失败后不会误提交和生成结果质量。

- 画布持久后台任务：代码层已覆盖服务端接受任务后无浏览器连接继续完成、刷新恢复、四元组结果补丁校验、幂等提交、任务取消、失败重试、跨画布公平调度、能力/渠道并发限制、租约心跳以及 Gateway 重启后从上游任务号恢复。仍需在真实远程 Gateway 上人工执行一组文本、图片、视频、音频和爆款复刻成片，分别在排队、提交和轮询阶段刷新页面、切换画布、关闭浏览器，并确认全局任务中心状态与结果节点一致。

- 多画布并行：创建至少三个画布连续提交任务，确认前端不阻止提交，Gateway 按 `CANVAS_JOB_CONCURRENCY_*` 和 `CANVAS_JOB_CHANNEL_LIMITS` 排队，快速连续创建/修改不同画布后刷新仍全部存在。若要求电脑关机期间继续生成，必须使用持续运行的远程 Gateway；本机 Gateway 只能在重新启动后恢复持久任务。

- 本地一体启动：项目根目录新增唯一的 `npm run dev` 启动入口，同时管理 Gateway 8788 和 Vite 前端 3000；已有端口会复用，缺失服务会自动启动。管理后台请求 Gateway 失败时现在显示“Gateway 未启动”、重试按钮及 `--` 计数，不再把离线误显示成真实的“渠道 0 / 模型 0”；请求成功且目录确实为空时仍显示 0。需人工确认终端退出时两个自启动进程一同关闭，以及端口被其他程序占用时的提示是否清晰。

- 画布生成配置：修复“组装提示词”编辑器受画布 `select-none` 和缩放影响而不显示输入光标的问题；编辑器现在允许文本选择并显式使用当前画布主题的光标颜色，需人工确认不同缩放比例和浅色/深色主题下的光标可见性。

- AutoDL ComfyUI 视频渠道：管理后台已发布 1 个 `minimax-h3-autodl-auto` 自动入口及 7 个真实 H3 工作流，覆盖文生视频、多图参考 1–10/11–15 秒、首尾帧、多图多音频 1–10/11–15 秒和图音频口型同步。画布会按节点中的提示词、图片、音频、显式素材模式和时长严格选型；参考视频、素材超限、无匹配或重复路由会在提交付费任务前失败。代码层已验证参数模板、音频 Base64、横竖方方向映射、自动路由和单创意单任务；未执行真实付费生成。仍需人工分别验证 7 个工作流的原始 Token 鉴权、QUEUED/RUNNING/SUCCESS/FAILED、10/15 秒切换、首尾帧/口型同步显式选择、短效视频立即保存和刷新后按内部 `gt-*` 任务号恢复。

- 爆款复刻：超长视频下镜头数量较多时，单一分析复合节点的内部滚动与内存占用需真实视频验证。
- 爆款复刻：复合拉片节点刷新后会根据嵌套代表帧的 `storageKey` 从浏览器图片库恢复新 URL，避免持久化的旧 `blob:` 地址显示破图；本地图片确实缺失时改为缺帧占位。仍需人工验收离线、IndexedDB 被清理以及跨浏览器打开画布时的缺帧提示与后续策划体验。
- 爆款复刻：真实模型返回的 `ViralVideoAnalysis` 缺字段场景下，复合分析面板栏位兜底文本是否稳定可读需验证。

- 系统接入说明：新增独立的 GouYingAi 项目交接文档，覆盖本地启动、管理后台、Gateway REST API、模型能力请求头、图片/视频/文本/音频示例、Canvas Agent / MCP、前端路由、浏览器本地数据边界、云端模式、安全要求和 Docker 上游镜像差异；需由接入方按文末清单验证实际渠道协议、远程 Gateway 鉴权和视频任务轮询。

- AI 珠宝商品图：根据《生图模版》新增独立顶部入口 `/jewelry` 和专用画布，不归入视频带货分类。入口页说明商品一致性、参考替换和九类独立输出；新画布提供戒指商品原图必填上传位，以及首图背景模板、佩戴姿势参考两个可选上传位。默认可勾选商品首图、侧面图、背面图、立式侧面、手持展示、戒指盒图、佩戴图、手势变体和铅笔设计稿，每类可生成 1-10 套，一次最多 90 张。三视图按三张独立成品生成，不生成拼图；首图模板只迁移背景、构图和光线，佩戴参考只迁移手势和视角，所有任务均以商品原图作为戒指结构的唯一事实来源。九类分别使用独立的完整提示词，并在每张结果前创建可见的提示词节点，结果可在画布中单独修改和重试。真实模型生成按约定未执行，仍需人工确认多参考图顺序、隐藏角度推演、商品结构一致性、手部质量、Gateway 批量限流与失败重试。

- 项目宣传海报专用画布：入口已归入顶部唯一的“AI批量带货系统”，并在统一入口内作为独立的国内图片营销工作流展示，与美区视频带货生成逻辑保持分离；旧 `/poster` 地址会自动跳转至统一入口。新画布提供可选的项目截图/主视觉上传位，顶部填写项目介绍后即可直接生成，也可选择 3:4 / 9:16 / 1:1 比例和一次生成 1-10 张。已移除标签、主标题、副标题、三个卖点、CTA、强调色和预设版式等固定返回结构，也移除浏览器 Canvas 的固定中文排版合成。文本模型现在只返回原创创意名称、设计思路和可直接提交给生图模型的完整成品海报提示词；具体需要哪些文字、几段信息、视觉主体、构图、色彩与版式全部由 AI 根据项目决定。没有参考图时直接文生图生成完整海报，上传参考图时走图生图并要求保留项目主体与关键识别信息。生成链路保留“策划结果与完整策划提示词 → 独立完整成品海报提示词 → 海报结果”三个节点，便于直接核对两个真实请求。事实约束禁止编造融资、销量、客户、排名、认证、奖项、价格等未提供信息。真实模型生成按要求未执行，仍需人工确认统一入口跳转、开放式策划 JSON、中文文字生成准确度、文生图/图生图、三种比例、批量并发和下载表现。

- AI 批量带货系统：顶部原“电商带货”和“项目海报”合并为一个统一入口。视频带货区按内容结构提供五类真实工作流：AI 硬广（数字人口播带货）、AI 视觉种草（AI 软广、无口播 / 轻旁白）、AI 剧情带货（故事植入）、AI 痛点对比短视频、AI 混剪解说（AI 配音 + 素材拼接）。五类不再共用同一段静态提示词：所有新工作流初始只展示商品图上传位，点击生成后先由多模态文本模型读取商品图并按分类动态策划，再创建策划节点和视频节点。硬广严格返回前三秒钩子、数字人设定、逐字英文口播、商品镜头、表演与声音；视觉种草返回视觉概念、氛围美术、无口播镜头序列、环境音或唯一一句轻旁白；痛点对比返回具体痛点、使用前、商品使用过程、可信结果和本条合规边界；混剪解说返回解说主题、逐字英文配音、逐句素材表、剪辑结构和声音设计；每类 JSON 字段、导演角色、内容边界与最终视频提示词都独立。AI 剧情增加单条剧情、三集迷你短剧和 3-20 集连载模式，可选择真人短剧/AI 漫剧、智能混合/逆袭打脸/情感误会/职场救场/家庭关系/悬疑揭秘/轻喜剧反差玩法，以及智能植入/解决问题的工具/推动关系的礼物/揭晓身份的证据/贯穿全剧的信物/触发冲突的道具。AI 剧情点击生成后为每套创意动态返回结构化剧本、角色设定、连续性和逐集视频指令；前端固定内容只保留美区方向、15 秒上限、所选玩法/植入方式与商品真实性、原创合规边界，不固定人物数量、性别、关系、场景或换场秒点。角色卡改用“固定画面与材质规范 + 真人/漫剧风格段 + AI 剧本动态角色外观段”的提示词模板：固定全身站立正面、纯白背景、简单落影、无文字和原创合规边界，角色人数、年龄、族裔、面孔、体态、发型、服装与配饰全部取自每套 AI 剧本，不固定女主、男主或单人；同套多集沿用该角色卡，不同创意重新生成。剧本节点会显示实际提交给生图接口的完整角色卡提示词。文本模型未配置或分类 JSON 返回无法解析时明确停止，不回退到通用提示词。所有成片固定按 15 秒任务规划，总输出最多 100 条；策划准备仍有浏览器内并发，成片任务的执行并发由 Gateway 配置。真实模型批量生成按要求未执行，仍需使用实际文本/生图/视频渠道确认五类专用字段、策划节点、最终提示词、角色全身构图、人物与商品一致性、限流、费用和失败重试表现。

- 爆款复刻工作流：`/ecommerce` 新增独立“爆款复刻”入口，在无限画布中必需上传参考视频，替换素材完全可选。只有原生 Gemini 渠道或模型目录中显式标记 `nativeVideoInput` 的绑定才读取完整视频与音轨；Gateway 会把画布的 OpenAI 兼容消息转换为 Gemini `generateContent + inlineData`，禁止再根据 `gemini-*` 模型名猜测视频能力。其他文本模型按真实时间抽取带时间戳的画面作为降级证据。已用 `gemini-3.7-flash-high` 对同一原始 MP4 完成原生端点与画布网关端到端验证，均准确识别拟人牛排落入煎锅的连续动作；完整拉片 JSON 可解析为 1 个真实连续镜头、3 个语义动作节拍和声音策略，仍需在真实画布中验证条件细化及复合节点呈现。分析除时间轴、叙事、镜头语言、影像、声音和整体风格外，还会生成具体可替换元素清单；画布使用单个素材库大卡片承载多个替换对象，每个对象可绑定多张参考图。每套“复刻方案”统一确定人物、商品/替换对象、场景和内容，并生成全片连续性规则；所有动作节拍继承同一套元素，不再按镜头独立变人、变商品或变场景。无论拉片包含多少分析分段，每套方案只提交一次视频生成并只创建一个完整成片节点；原片时长超过模型上限时在单条成片内按比例压缩完整镜头结构。最终请求会显式包含多元素参考图绑定、方案级元素、全片连续性、原创换角规则与商品物理稳定性规则，固定使用竖屏 9:16；不向视频生成模型传入原视频画面或音频。单次最多生成 100 套方案，成片全部提交 Gateway 后台队列。代码层已覆盖多对象多图绑定、零素材直出、一套 14 节拍方案只创建一个复合节点和一套方案一条付费任务；仍需人工用真实模型复测素材卡交互、刷新恢复、多参考图顺序、人物/商品/场景连续性、单任务计费、15 秒结构压缩及最终成片质量。
