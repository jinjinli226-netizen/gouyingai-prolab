# 爆款复刻拉片节点信息密度优化设计

## 目标

保留每个动作节拍的代表帧，同时把仅供模型生成使用的连续性状态从主界面隐藏，让拉片结果能快速浏览且不改变既有分析、质检和生成逻辑。

## 展示规则

- 第一列继续完整展示代表帧，使用 `object-contain`，不裁切原图。
- 行标题统一为“动作节拍 N · 真实镜头 M · 开始时间–结束时间”。
- 代表帧下方保留画面描述，并只追加一行边界摘要。
- 第一个动作节拍的边界摘要固定显示“视频起始”；后续节拍显示模型返回的边界原因。
- `boundaryType`、`startState`、`endState`、`continuityFromPrevious` 继续保存在分析数据中，并继续参与质检和生成提示词，但不在复合节点主表格逐项展开。
- 其余叙事、时间、镜头语言、影像处理和声音栏位不变；不触发重新拉片或视频生成。

## 验收

- 代表帧仍可见且未被裁切。
- 主界面不再出现“节拍边界与状态”大段文本。
- 第一节拍显示“边界：视频起始”，其余节拍显示一行真实边界原因。
- 标题同时可见动作节拍编号、真实镜头编号和时间范围。
- 现有节点数据和爆款复刻生成流程不变。
