# 原生爆款视频复刻工作流设计

## 目标

在 GouYingAI 无限画布内提供可直接运行的“爆款复刻”入口。用户不需要 Agent Skill，也不需要先写商品描述：选中参考视频后点击一次即可开始拉片；拉片完成后可以补充任意替换参考图，最后点击一次生成完整复刻视频。

## 用户流程

1. 用户在任意画布选中一个已经上传的视频节点，点击底部工具栏“爆款复刻”。
2. 当前画布就地进入爆款复刻模式，复用该视频作为源视频，创建一个可选的替换元素素材库大卡片，并自动开始拉片。
3. 如果点击入口时没有选中视频，则创建新的爆款复刻画布，显示源视频与可折叠的替换元素卡片。
4. 拉片完成后，系统在卡片中自动列出具体人物、商品、场景、车辆和关键物品。用户可以同时替换多个对象，每个对象可上传多张多角度参考图；完全不上传素材时直接纯 AI 复刻。
5. 用户点击“一键生成复刻视频”。系统先生成结构化重制方案，再自动提交视频任务，不要求用户再次点击“生成提示词”。
6. 画布保留源视频、拉片复合节点、可编辑提示词节点、替换元素素材库卡片和完整成片节点，便于检查、修改与重试。

## 架构

### 画布入口

`CanvasToolbar` 增加“爆款复刻”按钮。入口逻辑优先使用当前选中的有效视频节点；未选中视频时调用现有 `buildViralVideoRemakeProject` 创建专用画布。

### 工作流激活

新增纯函数负责把普通画布节点转换为 `ViralVideoRemakeWorkflowState`：

- 保留源视频节点及其本地素材引用。
- 创建新的替换元素素材库复合节点。
- 初始阶段为 `idle`。
- 已存在爆款复刻工作流时不重复创建占位节点。

激活后，页面使用明确传入的 workflow 和已同步的 `nodesRef` 启动现有拉片函数，避免依赖下一次 React 渲染。

### 替换元素

工作流使用 `replacementNodeId` 指向一个配置型复合卡片。卡片保存由拉片识别的替换对象及其多张参考图，策划模型和视频模型按稳定顺序接收全部素材，并在提示词中写明每张图对应的元素。没有素材时不阻止策划或生成，直接执行纯 AI 复刻。

### 一键生成

拉片后的主操作统一为“一键生成复刻视频”：

- `analyzed`：设置一次性自动生成标记并开始策划。
- `planned`：直接提交完整成片。
- 策划成功进入 `planned` 后，页面消费一次性标记并自动提交。
- 策划失败、用户取消、源视频或替换素材变化时清除标记，禁止后续误提交。

每套创意只创建一个付费视频任务。镜头分段只用于分析和组织提示词，不拆成多个视频任务。

## 错误与费用保护

- 未选中视频时只创建空白工作流，不触发模型调用。
- 未配置文本模型时在拉片前停止。
- 未配置视频模型、模型能力不匹配或时长不支持时，在提交付费任务前停止。
- 用户点击“一键生成复刻视频”视为对当前显示套数的生成授权；批量上限继续保持 100。
- 自动链路标记只消费一次，失败后必须由用户重新点击。

## 测试

- 纯函数测试：普通画布激活、避免重复占位、无视频拒绝激活。
- 提示词测试：支持多个替换对象、同对象多张参考图、明确素材绑定，并允许零素材直接生成。
- 状态机测试：`idle` 对应拉片，`analyzed` 对应策划并自动生成，`planned` 对应直接生成。
- 集成源码测试：工具栏入口已接线，策划成功后只自动提交一次。
- 验证：运行爆款复刻专项测试、TypeScript 类型检查和 Vite 构建；最后在 `127.0.0.1:3000` 检查按钮与主操作文案。
