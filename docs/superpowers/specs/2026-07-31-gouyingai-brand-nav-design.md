# GouYingAi 品牌与顶部导航设计

## 范围

- 将 Web 应用中面向用户的产品名从 `ProLab` 更新为 `GouYingAi`。
- 使用用户提供的品牌图作为完整 Logo，并提供适合导航栏和 favicon 的紧凑图形标。
- 将桌面顶部主导航相对整个窗口居中，并增强当前页面的高亮与切换动画。
- 清空第三方默认 API 地址与预置模型，让用户首次使用时配置自己的兼容接口。
- 移除产品运行界面的 GitHub、在线文档、远程版本检查和上游推广入口。
- 将浏览器存储键、localForage 数据库名、WebDAV 清单、画布导出文件中的应用标识统一改为 `gouyingai`。
- 保留仓库中的 AGPL 许可证与必要原作者法律声明，不在产品主界面展示推广入口。

## 资产策略

- 完整 Logo 用于首页等允许较大展示面积的位置。
- 紧凑图形标只保留品牌符号，用于 24px 导航图标和浏览器 favicon。
- 两种资产都放在 `web/public/`，组件只引用稳定的公开路径。

## 顶部导航

- 顶栏使用三段布局：左侧品牌、中间主导航、右侧状态与设置。
- 桌面端中间导航使用绝对定位与水平平移，相对视口真正居中，不受左右内容宽度影响。
- 当前项采用更清晰的文字颜色、浅色背景和底部强调线；背景与强调线使用 180-220ms 缓动动画。
- hover 仅提供轻量背景和位移动画，避免改变元素尺寸或造成布局抖动。
- 移动端保留现有抽屉导航，不强行把完整导航塞进窄屏。

## 错误与兼容

- Logo 加载失败时仍显示 `GouYingAi` 文本，不影响导航使用。
- 不修改现有路由和请求协议。
- 本地数据键从 `prolab:*` 直接切换为 `gouyingai:*`，不迁移旧浏览器数据。
- 默认渠道保留为空配置，不预置第三方 Base URL、模型或 API Key。
- 用户提供的原图保留为源资产，紧凑图形标作为派生展示资产。

## 验证

- 运行现有前端测试和生产构建。
- 检查首页、普通工具页和画布项目页的品牌显示。
- 使用桌面和移动视口确认导航居中、当前项高亮、hover 动画、文本溢出与 favicon。
